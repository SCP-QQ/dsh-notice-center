通知中心：系统通知增加声音提醒（完成 / 待处理两种预置提示音）

1. 宿主 schema 新增 notifySound（默认 true）；设置页「系统通知」展开后新增「声音提醒」开关。
2. 提示音用 Web Audio 合成，不依赖任何音频资源文件：完成 = 上行双音（660 → 990Hz），待处理 = 下行双音（880 → 587Hz），音高走向不同，便于不看屏幕也能区分。
3. 发送通知时按类型播放对应提示音；开启声音时把通知本身设为 silent，避免与系统默认音叠加；关闭声音则交回系统默认提示音。
4. 音频上下文在用户打开通知开关的手势内预热（primeChime），满足浏览器自动播放策略；不支持 Web Audio 时静默降级，不影响通知本身。
5. 验证：node 语法校验 + mock 冒烟测试（提示音断言为 [660,990,880,587]、完成与待处理两条通知路径、通知 icon 为 data URI、单一设置分区）全部通过。
